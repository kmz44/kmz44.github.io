Requisitos del Sistema

  • Android 15+ (API 35)
  • 4GB de RAM mínimo (8GB recomendado)
  • 2GB de almacenamiento libre
  • ARMv8 (64-bit) o superior
  • Fuentes desconocidas habilitadas

Instrucciones de Instalación

Esta aplicación se instala como APK. Para instalarla:

  1. Descarga el archivo APK
  2. Ve a Configuración > Seguridad
  3. Habilita "Instalar aplicaciones desconocidas"
  4. Abre el archivo APK descargado
  5. Sigue las instrucciones de instalación
